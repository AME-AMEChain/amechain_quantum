# AME Chain

Official AME Chain Mainnet network information, RPC endpoints, explorer, and wallet configuration.

## Mainnet

| Parameter | Value |
|---|---|
| Network Name | AME Chain Mainnet |
| Native Token | AME |
| Symbol | AME |
| Chain ID | `180` |
| Network ID | `180` |
| Decimals | `18` |
| RPC URL | `https://node1.amechain.io` |
| Block Explorer | `https://amescan.io` |
| Website | `https://amechain.io` |

## RPC Endpoints

### Primary Mainnet RPC

```text
https://node1.amechain.io
https://node2.amechain.io
https://node3.amechain.io
https://node4.amechain.io
```

Use **node1.amechain.io** as the default public RPC unless an application specifically requires another node.

### AME Scan
AME Scan is the block explorer for AME Chain.

```text
https://amescan.io
```

### Important

Always verify that your wallet is connected to **AME Chain Mainnet** before sending **AME** or interacting with smart contracts.

Never share private keys, seed phrases, recovery phrases, or wallet credentials to anyone.
